# Product plan — ПРОБКА

## Product goal
A fast, offline-first traffic-jam puzzle for a global audience, with language-neutral core gameplay and localization-ready UI.

## Milestone 1 — playable prototype
- Native Kotlin/Android app
- Drag-and-slide car mechanic
- Level progression and local best score
- GitHub Actions APK build

## Milestone 2 — quality gate
- Verify every level is solvable and not accidentally impossible
- Add a level editor/test generator and automated collision/rule tests
- Test on at least one low-end and one modern Android phone
- Add English/Russian localization resources and responsive layouts
- Accessibility: contrast, touch targets, reduced motion

## Milestone 3 — retention
- 100 curated levels, daily challenge, streaks and shareable result cards
- No forced registration
- Measure tutorial completion, level completion, D1/D7 retention and session length with privacy controls

## Milestone 4 — monetization
- Rewarded ads only when the player opts in
- One-time remove-ads purchase
- Optional cosmetic packs; no pay-to-win
- Validate consent, age rating, privacy disclosures and current Google Play / ad network policies
- Do not enable ads before store/legal configuration is complete

## Milestone 5 — distribution
- Play listing assets and localized descriptions
- Internal test track, then closed test if required for the account
- Release AAB, crash monitoring, staged rollout and update cadence

## Budget discipline
- Use free source control, GitHub Actions free allowance and free design tools.
- Do not buy installs before organic retention is demonstrated.
- Keep a hard zero-cost prototype phase; account/store fees are deferred until publication is approved.
